# Physics 12

A study and practice companion to Giancoli, *Physics: Principles with Applications*, seventh edition, supplied as `Physics12.pdf`.

Open [index.html](index.html) or [content.html](content.html).

- [Tutorial](physics12-tutorial.html): all 33 chapters, 161 embedded teaching pictures covering every concept subsection and equation explanation, equations with concept-led derivations, 33 worked examples, 33 self-checks, search, chapter completion, and four interactive models. Study, Simple, and Slides modes support offline study and printing.
- [Practice Studio](physics12-practice.html): 2,722 original numbered problems, including general problems. Search and Learn sets are excluded. Chapter/topic filters, adaptive practice, typed answers, drawing, photos, review queues, student profiles, backups, and optional sync are included.
- [Activity monitor](physics12-monitor.html): read-only student practice history.
- [Source textbook](Physics12.pdf): chapter links use the verified 21-page offset from printed pages.

## Answer keys

The textbook supplies 1,348 final answers. All 1,374 missing answers are prebuilt and saved in `content/physics12/prebuilt-answers.json`, including solutions authored directly in an AI session. The builder preserves textbook answers and embeds valid saved entries as **Prebuilt AI answer**, with any saved worked steps, checks, and assumptions. AI answers are separate from the textbook key. A normal build requires all 2,722 problems to have a current saved answer, so **Show answer** works immediately offline. Incomplete builds fail before changing the existing page.

Development previews explicitly built with `--allow-missing` retain a fallback: **Show answer** generates a missing answer from the original question and referenced figures, marks it **AI-generated answer**, and caches it on the device for offline reuse. Generation sends no student names, written responses, drawings, or progress. The first request needs internet access; connection failures show an explicit retry action and do not record a score or display a placeholder as a solution. Cached answers are invalidated when their source question or images change. Textbook and prebuilt answers always open immediately, independently of online grading.

Generation reads only question images, referenced figure pages, and question text. It does not read student progress. Re-running skips valid saved answers and fills only missing or stale entries. The default is one request at a time to the studio's existing AI service.

```sh
python3 tools/generate_physics12_answers.py --status
python3 tools/generate_physics12_answers.py --build
# Rebuild only if every answer is already saved:
python3 tools/build_physics12_practice.py
# Explicit development preview with on-demand generation:
python3 tools/build_physics12_practice.py --allow-missing
```

Generation requires PyMuPDF and internet access. Building from the inventory/key uses the Python standard library. Generation saves each successful batch, so interrupted runs can resume. `--build` requires a complete, current prebuilt key before rebuilding an entirely offline page. Use `python3 tools/build_physics12_practice.py --require-prebuilt` to enforce the same check without generation.

Answers may also be authored directly in an AI coding session, using the original question images and referenced textbook material. Save these with `provenance: "prebuilt-ai"` and `generationMethod: "in-session"`, the current source fingerprint, and a generation date; the same completeness and validation checks apply. No page or online generation service is needed for this workflow.

When **Show answer** opens a key, it also shows any saved step-by-step solution. If worked steps are missing, it automatically requests an **AI-generated worked solution** using only the original question, diagrams, and reference key. The final answer stays visible while the solution loads. The first generation needs internet; successful solutions are cached on this device for offline reuse. Retry and cancel controls do not score an answer or block self-rating. Equations render with bundled offline KaTeX, including vectors, subscripts, powers, fractions, and inline/display LaTeX. Previously saved Unicode equations and numbered steps are formatted on display without deleting cached solutions. Keep `assets/physics12-math/` beside the page for the math fonts. The solution cache is separate from student progress and is invalidated when the source question or final key changes. Textbook keys remain unchanged.

## Offline files and local image review

Keep `assets/physics12-practice/` beside the HTML pages, including the `.png.js` companions generated by the builder. The local image loader reads the requested image bytes for AI canvas export and avoids the tainted-canvas error when the page is opened directly as a local file. No local web server is required. Keep `Physics12.pdf` for original-page links.

Textbook, prebuilt, and device-cached answers, drawings, progress, and review queues work offline. First-time generation of a missing answer, live AI help, answer verification, and Firebase sync require internet access. Progress uses the `physics12` namespace; rebuilding pages does not overwrite browser history.

## Sources and rebuilding

- `content/physics12/practice-problems.json` records all question IDs, original pages, image rectangles, referenced figures, and textbook answer images.
- `content/physics12/prebuilt-answers.json` stores generated answers, source fingerprints, generation dates, and provenance.
- `tools/build_physics12_practice.py` builds the studio and monitor. Use `--extract` to regenerate question crops/inventory from the PDF (requires PyMuPDF and Poppler); `--refresh-context` refreshes figure references.
- `tools/physics12-practice-template.html` and `tools/physics12-*.js` hold the studio layout and behavior.
- `tools/physics12_content.py` holds tutorial content. `tools/physics12_visuals.py` holds 104 original vector diagrams and explicitly maps them to all 99 concept subsections and 62 equation explanations. Each placement includes an accessible text description, a reading guide, and a prediction with a revealable answer. Enlarge controls open a keyboard-accessible zoom dialog for small screens; all pictures work offline and print with their prediction answers. `tools/physics12_derivations.py` holds original equation explanations with concepts, assumptions, numbered steps, results, checks, and chapter links mapping the [44-chapter university review](https://cghuisunshine.github.io/Physics_uni/Physics_Review_and_Summary_Tutorial.html) into the 33 tutorial chapters. Explanations are searchable and expandable; printing opens all derivations in matching chapters and restores the reading state afterward. `python3 tools/build_physics12_tutorial.py` rebuilds the tutorial using the installed chapter-tutorial-html skill. Its template is `tools/physics12-template.html`.

The full source book extends beyond a typical Physics 12 course; use chapter and topic filters to select material.
